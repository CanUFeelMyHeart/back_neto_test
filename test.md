# Инструкция по Гиту

## 1. Создание репозитория

> **git init** - инициализация  репозитория.

# 2. Просмотр текущего состояния в git

> **git status** - получить информацию от git о его текущем состоянии (*все ли изменения в файлах добавлены в **отслеживание***)

## 3. Добавить файл или файлы к следующему коммиту

> **git add .** - все файлы, в которых были изменения
> **git add filename** - конкретный файл по 
имени
