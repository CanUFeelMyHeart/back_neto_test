# Инструкция по Гиту

## 1. Создание репозитория

### **git init** - инициализация пустого репозитория.

# 2. Просмотр текущего состояния в git

### **git status** -  инфо о текущем состоянии (*все ли изменения в файлах добавлены в **отслеживание***).

## 3. git add используется, чтобы добавить файлы к коммиту, который идет следующим

### **git add .** - **все** файлы, в которых были изменения.
Например: **git add test.md**
### **git add filename** - добавить файл с именем **filename** в отслеживание


## 4. Перемещение по истории коммитов и движение по веткам

### **git checkout commit_id** - для перемещения в нужную версию по id коммита
### **git checkout branch_name** - переместиться в ветку с именем branch_name
